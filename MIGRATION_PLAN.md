# 🚀 План миграции проекта ZverskiNapalen на Next.js + Supabase

## 1. Цели и задачи
- Перевод статичного сайта на **Next.js (App Router)** с React 19/18.
- Полная интеграция **Supabase Auth & Database** (пользователи, аватары в Storage, отзывы РЗТ с оценками).
- **100% сохранение всех визуальных и звуковых эффектов, пасхалок и Canvas-игры**.
- Устранение багов, утечек памяти, небезопасного хранения паролей и рассинхронизации данных.
- Устранение 2400+ строк дублирующегося HTML/JS кода (объединение страниц альбомов и треков в единую data-модель).

## 3. Пошаговый план реализации

### Фаза 1: Инициализация и настройка структуры
1. Создание Next.js проекта со структурой App Router.
2. Перенос всех медиа-файлов (`images/*`, `game/*.png`, gif) в `public/`.
3. Настройка глобальных стилей, анимаций (`@keyframes bgScroll`, `bgMove`, `floatLogo`, `crtFloat`, `shakeLetter`) и шрифтов (`Orbitron`, `Roboto`, `Press Start 2P`).

### Фаза 2: Supabase слой и AuthContext
1. Установка `@supabase/supabase-js` и `@supabase/ssr`.
2. Создание типизированного клиента Supabase.
3. Разработка `AuthContext`:
   - Отслеживание `onAuthStateChange`.
   - Автоматическая подгрузка расширенного профиля из таблицы `users` (`nickname`, `photo`, `about`).
   - Методы `login`, `register`, `logout`, `updateProfile`, `uploadAvatar`.
   - **Устранение уязвимости**: исключить сохранение паролей в открытом виде в таблице `users`.

### Фаза 3: Аудио-движок и общие эффекты (Layout)
1. Реализация хука `useAudioSynth` для синтеза всех звуков на Web Audio API:
   - `playDiveSound()`: синусоида 800 Гц $\to$ 60 Гц.
   - `playBarkSound()`: прямоугольный импульс 300 Гц $\to$ 80 Гц.
   - `playDoubleBeep()`: 1600 Гц + 1900 Гц.
   - `startWhiteNoise()` и `playTypewriterClick()`.
2. Компонент `Header`: интеграция лая при клике на логотип, индикатор авторизованного пользователя.
3. Компонент `AnimatedBackground` и хук `useFlyingLogos`: спавн до 15 фоновых логотипов по таймеру и клику + редкий пролёт переднего гигантского логотипа (с корректной очисткой таймеров и DOM-узлов при unmount).
4. `SoundCloudPlayer` и `ScrollToTopButton`.

### Фаза 4: Реализация основных страниц
1. **`/` (Landing)**: Анимация разрастающегося черного круга + 11-секундный таймер бездействия (50% шанс появления пса на 5с) + звук дайва.
2. **`/main`**: 6-секундный fade-in, блоки ссылок, спавн собачек.
3. **`/diskografiya`**:
   - Вынесение всех 25+ треков в `data/tracks.ts`.
   - 3D-вращение обложек при наведении (`rotateX(720deg) rotateY(720deg)`).
   - Карусель с поддержкой стрелок и свайпа.
   - Плавающее перетаскиваемое окно трека (drag & drop за заголовок с удержанием в границах вьюпорта, табы "Текст" / "История").
   - Модалка "Все треки".
4. **`/album/[slug]`**:
   - Единый шаблон для `mcuboyniystaffchikep`, `elmao`, `elmao2`.
   - Интерактивное переключение текстов треков и описания альбома.
5. **`/rzt` и `/reviews`**:
   - `/rzt`: Выбор трека, 5 слайдеров с авто-расчетом общего балла `(base * 1.4 * (1 + (vibe - 1) * 0.06747))`, запись в Supabase `reviews`.
   - `/reviews`: Список всех отзывов из Supabase с аватарами, редактирование и удаление только для авторов (сравнение `user_id`).
6. **`/login` и `/profile`**:
   - Вход, регистрация, загрузка аватара в Supabase Storage `avatars`, редактирование ника и описания.

### Фаза 5: Игра и Секретные страницы
1. **`/game`**:
   - Компонент `GameCanvas`: инициализация Canvas, загрузка спрайтов из `/game/`, игровой цикл `requestAnimationFrame`, корректный cleanup слушателей клавиатуры.
2. **`/azazazatrolil`**:
   - CRT-эффект, фоновый белый шум, печать текста со звуком и тряской букв, шаги эскалации с увеличением громкости и размера, 5-секундный blackout и редирект в `/lol`.
3. **`/lol`**:
   - Бесконечный движущийся паттерн мема.
4. **`/manifest` и `not-found.tsx`**:
   - Колбасня пса (шейк по формуле `(1 - progress) ** 2`) + стартовый двухтональный писк.
